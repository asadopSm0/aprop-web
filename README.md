# Aprop landing page

Landing page premium para Aprop, una plataforma de micro-ayuda para personas mayores basada en confianza,
proximidad y autonomía.

## Arquitectura

- `index.html`: estructura semántica de la landing.
- `styles.css`: sistema visual, layout responsive, estados y microinteracciones.
- `script.js`: navegación móvil, header adaptativo y animaciones por aparición.
- `assets/`: fotografía hero, servicios y testimonial.

## Dirección visual

- Paleta: coral, navy, turquesa, crema y grises cálidos.
- Tipografía: `DM Serif Display` para titulares y `DM Sans` para interfaz/cuerpo.
- Estética: editorial, humana, cálida, con contraste entre fotografía y superficies limpias.
- Composición: bastante aire, secciones amplias, cards grandes, glassmorphism puntual y sombras suaves.

## UX y accesibilidad

- Jerarquía muy clara: confianza, funcionamiento, servicios y conversión.
- Navegación sticky y responsive.
- Contraste suficiente, enlaces visibles y estructura semántica.
- `skip-link`, textos alternativos y soporte para `prefers-reduced-motion`.
- Copy corto, concreto y emocional, evitando densidad innecesaria.

## Microinteracciones

- Header translúcido que gana presencia al hacer scroll.
- Revelado suave de bloques al entrar en viewport.
- Zoom sutil de imágenes de servicio en hover.
- Menú móvil plegable y CTAs con elevación ligera.
